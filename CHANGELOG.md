## [0.1.0] - 2026-02-14

### Added
- Initial release of MacShot screenshot tool
- Fullscreen, region, and window capture modes
- Annotation tools: Rectangle, Ellipse, Line, Arrow, Text, Number, Spotlight
- Export to PNG/JPEG with quality control
- Copy to clipboard functionality
- Hotkey support (Cmd+Shift+5/6/7)
- Menu bar integration
- Settings persistence via UserDefaults

## Versioning Scheme

- **Major.Minor.Patch** (e.g., 1.2.3)
- Major: Breaking changes, new features
- Minor: New features, backward compatible
- Patch: Bug fixes, small improvements
