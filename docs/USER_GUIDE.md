## Getting Started

### Requirements

- macOS 15.0 or later
- Screen recording permission (first launch)

### First Launch

1. Open MacShot from Applications folder
2. Grant screen recording permission when prompted
3. Menu bar icon appears (top-right of screen)

## Capturing Screenshots

### Fullscreen Capture

**Hotkey**: Press `Cmd+Shift+5`

**Menu**: Click menu bar icon → "Capture Fullscreen"

Captures all connected displays as a single image.

### Region Capture

**Hotkey**: Press `Cmd+Shift+6`

**Menu**: Click menu bar icon → "Capture Region"

1. Screen dims, selection overlay appears
2. Click and drag to select area
3. Release to capture

**Tip**: Press `Esc` to cancel selection

### Window Capture

**Hotkey**: Press `Cmd+Shift+7`

**Menu**: Click menu bar icon → "Capture Window"

1. Screen dims, hover over windows
2. Click target window to capture
3. Only that window is captured (transparent)

## Annotating

After capturing, the editor opens automatically.

### Tools

| Tool | Description | Use Case |
|------|-------------|-----------|
| **Select** | Select and move shapes | Repositioning |
| **Rectangle** | Draw rectangles | Highlighting areas |
| **Ellipse** | Draw circles/ellipses | Emphasizing regions |
| **Line** | Draw straight lines | Dividing sections |
| **Arrow** | Draw directional arrows | Pointing to items |
| **Text** | Add text labels | Captions, explanations |
| **Number** | Add numbered markers | Step-by-step guides |
| **Spotlight** | Darken surroundings | Focusing attention |

### Using Tools

1. Click tool button in toolbar
2. Click/drag on canvas to draw
3. Shape appears with default style

### Select Tool

- Click any shape to select
- Drag selected shape to move
- Press `Delete` to remove selected

### Undo/Redo

- **Undo**: Click undo button or press `Cmd+Z`
- **Redo**: Click redo button or press `Cmd+Shift+Z`

### Style Controls

- **Color**: Click color button to choose stroke/fill
- **Stroke Width**: Drag slider to adjust line thickness
- **Opacity**: Adjust transparency level

### Presets

Quick style combinations:

- **Red Preset**: Red stroke, no fill (default)
- **Blue Preset**: Blue stroke, no fill
- **Green Preset**: Green stroke, no fill
- **Highlight**: Yellow stroke, yellow fill (30% opacity)

## Exporting

### Export Button

Click "Export" in toolbar to open export options.

### Format Options

| Format | Best For | Transparency |
|--------|----------|----------------|
| **PNG** | Screenshots, text | Yes |
| **JPEG** | Photos, smaller files | No |

### Quality (JPEG only)

- **High** (0.9-1.0): Best quality, larger files
- **Medium** (0.7-0.9): Balanced
- **Low** (0.5-0.7): Smallest files, artifacts

### Save to File

1. Click "Save" button
2. Choose destination in file picker
3. Enter filename (auto-generated by default)
4. Click "Save"

**Default location**: Desktop folder

**Default filename**: `MacShot_YYYY-MM-DD_HHmmss.png`

### Copy to Clipboard

1. Click "Copy" button
2. Image copied to system pasteboard
3. Paste anywhere (`Cmd+V`)

**Hotkey**: `Cmd+Shift+C` (quick copy from editor)

### Quick Save

**Hotkey**: `Cmd+S` (opens save dialog directly)

## Troubleshooting

### Capture Permission Denied

**Symptom**: "Screen recording permission required" message

**Solution**:
1. Open System Settings → Privacy & Security
2. Go to Screen Recording
3. Enable MacShot
4. Restart MacShot

### Editor Doesn't Open

**Symptom**: Capture completes but editor doesn't appear

**Solution**:
- Check if MacShot has window focus
- Try capturing again
- Restart MacShot if persists

### Export Fails

**Symptom**: "Export failed" error message

**Solution**:
- Verify destination folder exists
- Check available disk space
- Try different format (PNG → JPEG)
- Check file permissions

### Hotkeys Not Working

**Symptom**: Pressing hotkeys does nothing

**Solution**:
1. Open Settings → Hotkeys
2. Verify hotkeys are enabled
3. Check for conflicts with other apps
4. Customize to different keys if needed

### Poor Performance

**Symptom**: Slow captures or editor lag

**Solution**:
- Close other apps
- Reduce capture resolution
- Disable transparency in JPEG
- Check available RAM

### File Too Large

**Symptom**: Exported files too large

**Solution**:
- Use JPEG instead of PNG
- Lower JPEG quality to 0.7-0.8
- Capture smaller region
- Crop before export

## Tips & Tricks

### Quick Workflow

```
1. Cmd+Shift+5 (capture fullscreen)
2. Click Rectangle tool
3. Draw highlight box
4. Cmd+Shift+C (copy to clipboard)
5. Cmd+V (paste in destination)
```

### Numbered Steps

1. Capture screen
2. Use Number tool to mark steps: 1, 2, 3...
3. Add text for each step
4. Export for tutorials

### Focus Mode

1. Capture screen
2. Use Spotlight tool
3. Drag center to focus point
4. Adjust radius with slider
5. Export for presentations

### Comparison

1. Capture "before" state
2. Keep editor open
3. Make changes
4. Capture "after" state
5. Annotate differences with arrows
6. Export side-by-side comparison
